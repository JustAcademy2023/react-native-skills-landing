# React Native Skills Landing Page

A bold, playful, fully responsive landing page for **React Native Developer Skills: Complete Guide for Beginners**. Built with plain HTML and CSS, so there is nothing to install.

## Preview

Open `index.html` in any browser, or publish it with GitHub Pages.

## What is inside

- Sticky header with a demo button and smooth anchor navigation
- Hero section with an animated phone mockup
- Skills cards, a six month roadmap, course cards and guide cards
- Call to action block and a full footer, with every link clickable
- Scroll reveal animations that respect reduced motion settings

## Run it locally

1. Clone the repository
2. Open `index.html` in your browser

## Deploy with GitHub Pages

1. Push the files to the `main` branch
2. Go to Settings, then Pages
3. Choose `main` and the root folder, then save
4. Your page goes live at `https://your-username.github.io/react-native-skills-landing/`

## Customising

All colours live in the `:root` block at the top of the style section. Change the five colour variables to restyle the whole page in seconds.
